**WhoTouchedIt** is a web application developed as part of my final-year PPE project (Professional Project) for my BTS SIO degree.

Built using **PHP, Laravel, and Symfony**, the application is designed to manage and track maintenance operations on industrial machines.

It allows users to monitor machine conditions, schedule maintenance tasks, assign interventions to technicians, and keep a detailed history of completed operations.

The application also includes a role-based access control system, providing different permissions for technicians, maintenance managers, and administrators.

The main goal of WhoTouchedIt is to **improve maintenance organization, equipment traceability, and operational efficiency** in an industrial environment.
